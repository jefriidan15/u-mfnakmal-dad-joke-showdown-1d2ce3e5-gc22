## What it does

`main.ts` writes one original dad joke to `/output/entry.txt` — a father,
a thermostat, and a safe combination. Nothing else: stdlib only, no network,
no randomness, no clock, fully deterministic.

> My dad treats the thermostat like a safe combination. He nudges it one
> degree, waits, and whispers, "Almost cracked it."

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (Node runs the TypeScript directly).
